상권분석 사용설명서

지도 위 한 지점을 기준으로 반경 안의 상가·업종·추정 매출 규모를 공공데이터로 분석합니다.

1. 기본 사용법

  1. 왼쪽 위 반경(3m~2000m)을 고릅니다.
  2. 오른쪽 지도를 클릭하면 그 지점을 중심으로 분석이 시작됩니다.
  3. 왼쪽에 결과가 표시됩니다: 반경 내 상가 수, 추정 상권 규모(월간), 주요 업종 Top 5 도넛 차트.
  4. 지도에는 반경 원, 주변 상권 구역(다각형), 상가 위치가 함께 표시됩니다. 구역·상가를 클릭하면 상세 정보가 나옵니다.

2. 위치 찾기

주소 🔍도로명·지번 주소로 찾아 그 위치로 이동합니다.
상호 🔍가게·건물 이름으로 찾아 이동합니다.
시작 위치마지막으로 본 위치(기기별 저장)에서 시작합니다. 폰은 GPS 를 먼저 쓰고, 실패하면 마지막 위치를 씁니다.
※ PC 의 IP 위치는 통신사 거점(예: 성남)으로 잡힐 수 있어, 처음 한 번 주소 🔍 로 원하는 곳을 찾아 두면 다음부터 그곳에서 시작합니다.
내 위치위치 버튼을 누르면 저장된 위치를 무시하고 현재 위치를 다시 찾습니다.

3. 상권 🔍 · 업종 🔍 (상세 조회)

상권 🔍반경 내 주요 상권 구역 목록. 항목을 클릭하면 해당 상권 영역을 지도에서 분석합니다.
업종 🔍지도 반경 내 상가업소와 업종 목록. 항목을 클릭하면 지도에서 위치를 보여 줍니다.
도움말 ❓사용한 공공데이터와 추정치 산출 근거를 설명합니다.

※ 추정 매출은 상가 수 × 업종별 평균 가정치로 계산한 참고용 수치입니다.

4. 상단 버튼 (오른쪽 위)

업데이트GitHub 원격 저장소에 새 버전이 있는지 확인합니다. 없으면 "최신 버전", 있으면 변경 목록을 보여 주고 승인 시 내려받습니다(진행 바·로그 표시). 끝나면 앱을 재시작하세요. 의존성·화면 코드가 바뀌었으면 안내에 따라 install.bat 또는 npm run build를 실행합니다.
포털 서비스로 실행 중일 때는 보안상 앱 폴더에 쓸 수 없어 새 버전 확인만 됩니다. 적용은 start.BAT(개발 모드) 화면의 [업데이트] 또는 앱 폴더에서 git pull 후 포털에서 재시작하세요.
설명서이 페이지를 새 탭으로 엽니다.
종료캐시 삭제 → 서버 종료·포트(3000/8080) 정리 → 명령 창 닫기 → 브라우저 닫기 순으로 진행합니다.
포털 서비스로 실행 중일 때는 다른 사용자도 쓰고 있을 수 있어 서버는 유지하고 캐시만 지웁니다. 서비스 정지는 포털 관리자 화면에서 합니다.

5. 실행 방법

포털My Potal 의 상권분석 카드로 접속합니다(포트 7009). 같은 네트워크의 다른 PC는 http://이PC의IP:7009.
개발 모드install.bat으로 설치 후 start.BAT 실행 → http://localhost:3000.

6. 문제 해결

  • 지도가 안 나옴: 카카오 개발자 콘솔 → 플랫폼 → Web 도메인에 접속 주소(http://localhost:7009, http://IP:7009 등)를 등록하세요.
  • 분석 오류(API Key): backend\.env 의 DATA_GO_KR_API_KEY(공공데이터포털 인증키)를 확인하세요.
  • 업데이트 실패: 이 PC에서 고친 파일이 원격 변경과 겹치는 경우입니다. 변경을 정리한 뒤 다시 시도하세요.
