공공데이터포털 Open API 연동 안내

📊 Around Store 데이터 산출 근거 및 도움말

Around Store에서 제공하는 반경별 상가 분석, 업종 분포도, 상권 구역 및 추정 매출액 데이터의 수집 출처와 산출 알고리즘 안내입니다.

🏛️ 1. 데이터 공식 출처

소상공인시장진흥공단 상가(상권)정보 오픈 API (sdsc2)

본 서비스는 행정안전부 공공데이터포털(data.go.kr)을 통해 제공되는 소상공인시장진흥공단(SEMAS)의 공공데이터를 기반으로 실시간 조회 및 분석을 수행합니다.

  • 제공 기관: 중소벤처기업부 산하 소상공인시장진흥공단
  • 데이터 세트명: 소상공인시장진흥공단_상가(상권)정보 (OpenAPI)
  • 기본 엔드포인트: https://apis.data.go.kr/B553077/api/open/sdsc2/
  • 법적 근거: 공공데이터의 제공 및 이용 활성화에 관한 법률 (법률 제11956호)

📡 2. 활용 오픈 API 및 데이터 수집 원리

① 지정 반경 내 상가업소 및 업종 조회 storeListInRadius

사용자가 지도에서 클릭한 중심 좌표(경도 cx, 위도 cy)와 선택한 반경(radius, 3m ~ 2000m)을 기반으로 해당 영역에 위치한 상가업소 목록을 호출합니다.

  • 수집 데이터 항목: 상가업소명(상호명), 업종 대분류명(음식, 소매, 서비스 등), 중분류명, 도로명/지번 주소, 위도/경도 좌표
  • 활용 목적:
    • 반경 내 총 점포 수(Total Stores) 산출
    • 업종별 점포 점유율 및 상위 5대 업종 도넛 차트(Doughnut Chart) 구성
    • 지도상에 개별 점포 위치 마커 핀 표시
② 반경 내 주요 상권 구역 다각형 조회 storeZoneInRadius

선택 지점 주변에 공식 지정된 골목상권, 발달상권, 전통시장 등 주요 상권의 공간 구역 경계를 조회합니다.

  • 수집 데이터 항목: 상권번호(trarNo), 주요 상권명(mainTrarNm), 상권 경계 다각형 좌표(coords - WKT POLYGON 규격)
  • 시각화 원리: WKT(Well-Known Text) 좌표 문자열을 위/경도 좌표 리스트로 파싱하여 카카오맵 위에 실제 상권 다각형(Polygon)으로 시각화합니다.

🧮 3. 지표 산출 근거 및 추정 매출액 알고리즘

📊 1) 업종별 분포 및 비율 계산

반경 내 조회된 업종 대분류(indsLclsNm)의 점포 빈도를 집계하여 백분율(%)로 표출합니다.

공식: 업종별 비율(%) = (해당 업종 점포 수 ÷ 반경 내 총 점포 수) × 100
💰 2) 예상 월 매출액(추정치) 산출 방식

공공데이터포털 무료 Open API 정책상 개별 사업자의 실제 금융/카드 매출 원천 데이터는 공개되지 않습니다. 이에 따라 소상공인 주요 업종별 평균 매출 통계 가중치 모델을 적용하여 해당 반경의 총 예상 매출 규모를 추정합니다.

업종 대분류 적용 월평균 가중 매출액 (기준치) 비고
음식 4,500만 원 외식업 평균 테이블 회전율 반영
숙박 5,000만 원 호텔/모텔 객실 단가 반영
소매 2,500만 원 편의점, 의류, 잡화 등 유통 평균
관광 / 여가 / 오락 2,000만 원 PC방, 노래방, 실내체육 등
서비스 / 생활서비스 1,000 ~ 1,500만 원 미용실, 세탁소, 수리업 등
학문 / 교육 1,200만 원 보습학원, 교습소 등
부동산 800만 원 부동산 중개사무소 평균
추정 총 월매출 공식:
추정 월매출 = [∑(반경 내 업종별 점포 × 업종별 가중치)] × (전체 상가 수 ÷ 샘플 상가 수)

💡 4. 사용 팁 및 주의사항

  • 지도 클릭으로 빠른 탐색: 상단에서 반경(예: 300m, 500m)을 선택한 후 지도 위 원하는 위치를 클릭하면 즉시 해당 지점 중심으로 실시간 분석이 갱신됩니다.
  • 주소 및 상호 검색: 상단의 [주소 🔍] 또는 [상호 🔍] 버튼을 통해 특정 지번/도로명 주소나 관심 매장으로 바로 이동할 수 있습니다.
  • 상권 구역 클릭: 지도에 나타난 푸른색 상권 다각형 구역을 클릭하면 해당 상권 중심점으로 자동 이동 및 상세 분석이 진행됩니다.
  • 데이터 성격 안내: 표시되는 예상 월 매출액은 공공데이터 상가 수와 업종 통계 가중치를 결합한 추정 참고 지표이며, 실제 사업자의 세무/카드사 신고 매출과 다를 수 있습니다.
